# Gajae Code App v2.0.0-beta.13

Desktop build: 0.2.7. This is a beta release for iterative testing and the
first public version published after the click-driven updater shipped in
beta.12, so it doubles as the public A-to-B update check for that workflow.

## Updating from beta.12

- An installed beta.12 discovers this release automatically and shows the
  **Update** notice above Settings in the lower-left sidebar. Nothing is
  downloaded or installed until you click it.
- Clicking **Update** downloads the signed update and requests a safe restart.
  Active work, changed targets and failures defer the operation instead of
  forcing a restart.
- Earlier beta.10/beta.11 installers have their updater disabled: quit the old
  app and install this DMG manually once.

## What changed

- Browser panel: previews render at the viewer's bounded device pixel ratio
  with physical screencast dimensions and CSS-space pointer coordinates, so
  text is no longer blurry on Retina displays.
- Browser panel: focused Ctrl/Cmd copy, cut and paste are bridged as plain text
  to the local clipboard, including Korean keyboard layouts, mixed modifiers,
  readonly fields and reactive input events. Password fields are never copied.
- Sidebar: archived projects stay out of live sidebar updates while the
  selected session and new projects still appear.
- Chat history: the viewport is preserved when older messages load, loading
  starts at the top without an extra gesture, new-message badges reflect real
  tail growth, failed history loads show an explicit retry instead of looping,
  and GJC pagination counts visible rows so long transcripts load completely.
- GJC goals: persisted goal inspection is strictly read-only and never
  hydrates a session manager, so opening a project can no longer write to the
  transcript.
- i18n: history loading and retry strings are complete.
- CI: the macOS desktop shell is gated on every pull request; the Linux desktop
  lane is dispatch-only.

## Validation and beta limitations

This release retains the source-test, signature, notarization, archive
integrity, version and data-safety gates. It is not a declaration that every
update or failure scenario has been exercised.

- The beta.12 to beta.13 in-app update is the first public exercise of the
  click-driven updater; report any deferred or failed update with the sidebar
  update details.
- The bundle's loader minimum is macOS 13.0; real macOS 13 execution is not
  yet verified.
- Browser clipboard bridging is plain text only and requires a secure context
  with clipboard permission.
- Keep important project work committed or backed up before testing. Updates
  do not promise automatic rollback of user-data changes.

macOS desktop targets Apple Silicon. Linux server archives remain
manual-update distributions. No Windows or Intel Mac installer is supplied.
