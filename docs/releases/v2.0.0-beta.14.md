# Gajae Code App v2.0.0-beta.14

Desktop build: 0.2.8. This release replaces beta.13, whose macOS binary was
published with its updater compiled out.

## If you are on beta.12

The sidebar notice above Settings offers this version directly. Press
**Update** to download it, then **Restart to install** once it is verified.
The app closes briefly and reopens as beta.14.

## If you are on beta.13

beta.13 cannot update itself. Quit it, install this DMG once, and launch the
copy in Applications. If beta.13 was blocked at startup by "The update could
not be finished", this DMG starts normally; your projects and settings are
picked up as they were.

## What changed since beta.13

- Updater: a release build now refuses to guess its updater mode, and the
  release verifier refuses to publish a binary that reports anything but a
  production updater. This is what let beta.13 ship broken.
- Updater: a build without an updater no longer blocks forever behind the
  installation record that produced it; the record is set aside and the app
  opens.
- Updater: launching the app with only a downloaded update in its cache opens
  the app normally instead of showing a checking screen.
- Updater: after the download, the button reads **Restart to install** and
  explains that the app closes and reopens as the new version.
- Updater: an exhausted GitHub anonymous API limit is reported in Settings
  with its reset, checks wait for that reset instead of polling every minute,
  and a quiet check costs one request regardless of how many releases exist.
- Update screens use plain language about what is happening and what to do.

Everything in the beta.13 notes (browser preview clarity, clipboard bridging,
archived sidebar rows, chat history loading) is included.

## Validation and beta limitations

This release retains the source-test, signature, notarization, archive
integrity, version, updater-mode and data-safety gates.

- The beta.12 to beta.14 in-app update is the first public exercise of the
  click-driven updater with a correctly built successor.
- The bundle's loader minimum is macOS 13.0; real macOS 13 execution is not
  yet verified.
- Keep important project work committed or backed up before testing. Updates
  do not promise automatic rollback of user-data changes.

macOS desktop targets Apple Silicon. Linux server archives remain
manual-update distributions. No Windows or Intel Mac installer is supplied.
